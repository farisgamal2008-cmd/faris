# Birthday Surprise — Mom ❤️

## Files
- `index.html` — the birthday surprise website
- `assets/shedeeny.mp3` — the song supplied for the page
- `assets/mom.jpg` — add the original photo of Mom here (the photo itself was not available in the files attached to this turn)

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `README.md`, and the `assets` folder to the root of a GitHub repository.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After publishing, open the public GitHub Pages URL and test the audio on a phone. Browsers normally require a tap before audio plays.
6. Use the published URL to generate a QR code.

## Add Mom's original photo
Save the original photo as `mom.jpg` inside `assets/`, so the path is `assets/mom.jpg`, then upload it to GitHub along with the other files. The page already looks for that exact path.

The QR code feature uses an online QR generation service and requires an internet connection.
